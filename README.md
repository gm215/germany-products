# Elektro Meister 🇩🇪⚡ | معلم الإلكترونيات في ألمانيا

لعبة ويب تفاعلية ممتعة ومصممة خصيصاً لخبير بيع وصيانة قطع الغيار والإلكترونيات في ألمانيا!

![Elektro Meister Banner](assets/hero_avatar.png)

## 📖 قصة وفكرة اللعبة
أنت تقود ورشة ومتجر الإلكترونيات الذكي في برلين وميونخ! تتدفق عليك أحدث المكونات الإلكترونية الأصلية المصنعة وفق أعلى معايير الجودة الألمانية (Deutsche Qualität). مهمتك هي قيادة منصة التجميع الذكية، وتلبية طلبيات الشركات والمستشفيات والزبائن الألمان في مدن فرانكفورت، هامبورغ، وشتوتغارت، وتطوير المتجر لشراء شاحنات DHL وسفن التوصيل وروبوتات الصيانة الفائقة!

---

## 🎮 مميزات اللعبة (Features)
- 🧑‍🔧 **البطل الحقيقي**: شخصية اللعبة مستوحاة من صورة البطل الحقيقي كمعلم وخبير للإلكترونيات بألمانيا مع اقتباسات وردود صوتية وكتابية طريفة.
- ⚡ **قطع إلكترونية احترافية**:
  - معالجات فائقة الدقة (Core i9 & Ryzen CPUs).
  - كروت شاشة ألعاب عملاقة (RTX 4090 GPUs).
  - رامات DDR5 فائقة السرعة.
  - مكثفات ومقاومات ولوحات أم احترافية.
  - ختم الجودة الألماني (TÜV / Made in Germany Seal 🇩🇪) لتفعيل وضع السرعة الفائقة ومضاعفة الأرباح!
- ⚠️ **مخاطر وعوائق حقيقية**:
  - مكثفات منفجرة ومحترقة.
  - التماس كهربائي حاد.
  - تسريبات مياه التبريد السائل.
  - قطع صينية مقلدة ومغشوشة تخصم من رصيدك لمخالفتها المعايير الألمانية!
- 📦 **نظام طلبيات الزبائن الألمان (Customer Quests)**:
  - تجميعات خاصة لسيارات مرسيدس وبي إم دبليو، أجهزة طبية، وسيرفرات بنوك فرانكفورت.
- 🛒 **متجر الترقيات والتطوير (Shop Upgrades)**:
  - مغناطيس كهرومغناطيسي لجذب القطع عن بعد.
  - شاحنة التوصيل السريع (DHL Express) لمضاعفة الأرباح.
  - عازل تفريغ الشحنات الكهربائية (ESD Shield) للحماية من الانفجارات.
  - محطة لحام ليزرية للتحكم بالسرعة.
  - درون مساعد ذكي (Robo-Meister) لجمع القطع الذهبية تلقائياً.
- 🎵 **مؤثرات وموسيقى سينث ويف بتقنية Web Audio API**:
  - تعمل بالكامل وبشكل مدمج وبدون أي ملفات صوتية خارجية إضافية (أوفلاين 100%).
- 📱 **دعم كامل للهواتف والكمبيوتر**:
  - متجاوبة بنسبة 100% مع أزرار لمس للشاشات الصغيرة وحركة الماوس ولوحة المفاتيح.

## 🕹️ أسلوب التحكم (Controls)
- **كمبيوتر (PC)**:
  - أسهم لوحة المفاتيح `⬅️` / `➡️` أو مفاتيح `A` / `D`.
  - أو تحريك مؤشر الماوس مباشرة فوق الشاشة.
  - زر `P` أو `Esc` للإيقاف المؤقت.
- **الهاتف والأجهزة اللوحية (Mobile / Tablet)**:
  - لمس وسحب الإصبع على الشاشة.
  - أو استخدام أزرار (يسار / يمين) اللمسية المدمجة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **HTML5 Canvas**: رسومات متجهة دقيقة وعالية الجودة (High-DPI).
- **Modern Vanilla JavaScript (ES6+)**: بدون أي مكتبات ثقيلة، أداء فائق وسريع جداً (60 FPS).
- **Web Audio API**: محرك توليد نغمات ومؤثرات صوتية وموسيقى Synthwave ديناميكية بدون ملفات صوت خارجية.
- **Responsive CSS3 Glassmorphism**: ألوان نيون سايبربانك مستوحاة من الهوية الألمانية.

## 🚀 تشغيل اللعبة محلياً (Run Locally)
يمكن تشغيل اللعبة مباشرة دون الحاجة لأي خادم أو تثبيت برامج:
1. افتح ملف `index.html` في أي متصفح (Chrome, Firefox, Safari, Edge).
2. أو شغل خادم محلي خفيف:
```bash
python -m http.server 8080
```
ثم افتح: `http://localhost:8080`

## 🌐 النشر على GitHub Pages (GitHub Deployment)
لرفع اللعبة إلى حسابك على GitHub وتفعيلها كلعبة أونلاين مجاناً:
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub بالاسم الذي تفضله (مثلاً: `german-electronics-master`).
2. نفّذ الأوامر التالية من مجلد المشروع:
```bash
git remote add origin https://github.com/<YOUR-USERNAME>/german-electronics-master.git
git branch -M main
git push -u origin main
```
3. من إعدادات المستودع (Settings) -> **Pages**:
   - اختر فرع `main` واضغط **Save**.
   - ستصبح لعبتك متاحة للجميع عبر رابط مباشر مثل:
   `https://<YOUR-USERNAME>.github.io/german-electronics-master/`
